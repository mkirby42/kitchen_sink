# Product scope

Kitchen Sink is a company product. The hackathon **Must ship / Cut** freeze is gone.

## Do

Read `docs/REQUIREMENTS.md`. **Current product** is what exists. **Not built yet** is backlog you may implement when asked.

Update REQUIREMENTS (and `docs/interest.md` if interest/anonymity changes) in the same change as the behavior.

## Do not

- Treat the old cut list as forbidden
- Invent a second visual language unless the task is a restyle
- Add extra libraries when the existing stack already covers it
- Change matching/schema without following `kitchen-sink-matching` and writing a migration

## If tempted to block work

Ask: is this the product change the user asked for? If yes, build it. If it is unrelated drive-by scope, skip it.
